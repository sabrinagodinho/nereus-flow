# Nereus Flow

Simulador educacional independente para escoamento multifásico transiente.

## Uso online
O arquivo `nereus_flow.html` é standalone: publique-o em qualquer hospedagem estática (GitHub Pages, Netlify, Cloudflare Pages ou servidor web próprio) e abra pelo navegador.

## Uso local
Abra `nereus_flow.html` diretamente no Chrome/Edge/Firefox.

## Modelo
Drift-Flux educacional com volumes finitos 1-D, propriedades PVT simplificadas, gravidade, atrito, transferência térmica e perturbação de vazão.
