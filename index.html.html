Validação e rastreabilidade

O Nereus Flow separa claramente resultado do solver de referência publicada. O benchmark didático usa a geometria e condições reportadas na literatura para comparação metodológica.

Equações do Nereus Flow

Conservação de massa

∂(αk ρk)/∂t + ∂(αk ρk uk)/∂x = Γk

Drift-Flux

J = αg ug + αl ul
ug = C₀ J + Ud
αg = (J - ul) / (ug - ul)

Gás

ρg = P M / (Z R T)

Pressão

dP/dx = -(ρm g sinθ + ΔPf/Δx)

Energia térmica

dT/dx = - U Pwet (T - Tamb) / (ṁ Cp)

A formulação atual é um solver Drift-Flux educacional. A próxima camada de fidelidade é o sistema Two-Fluid totalmente acoplado e implícito.
